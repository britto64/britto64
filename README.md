# Hi, I'm Denis 👋
 
**I build and run the infrastructure and tooling behind online creators.**
 
Self-taught, based in Teresina, Brazil 🇧🇷. I keep a production homelab alive 24/7 and ship the tools that a gaming channel uses live on stream. Now moving into **Cloud / DevOps / Platform Engineering** and **AI application development**.
 
---
### 🌱 What I actually run
 
- A 24/7 homelab on **TrueNAS SCALE**: ZFS, Docker, Cloudflare Tunnel, Tailscale
- **CI/CD** that redeploys containers on every push (GitHub Actions → Docker Hub → NAS)
- Stream widgets and OBS overlays in **JavaScript**, running live for a gaming creator
- Full-stack apps with **Next.js + PostgreSQL** and LLM APIs
### 🌱 Currently
 
- Building a self-hosted **live-stream overlay & widget platform**
- Going deeper on Cloud / DevOps and documenting the journey in public
